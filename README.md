# 페리 프로모션 관제

매장 태블릿 게임(산타 굴뚝배달 · PELI SLIDE · 페리 크리스마스 · 떨어지는 선물 받기 · 페리치킨런)을 켜고 끄고, 성공 알림과 쿠폰을 관리하는 관제 화면입니다.

- `index.html` — 현재 관제 (v11: v10에 페리치킨런 추가 · v10: V9에 페리 크리스마스·떨어지는 선물 받기 추가)
- `backup/control_v9_original.html` — 고치기 전 V9 원본

## 여는 주소
GitHub Pages를 켜면 `https://uniclub24-cpu.github.io/GAMECONTROLER/` 에서 열립니다.
(Settings → Pages → Branch: `main`, 폴더 `/ (root)` → Save)

`main`에 수정이 올라오면 1~2분 안에 같은 주소의 화면이 바뀝니다. 서버 주소·공개 키·로그인 정보는 파일에 들어 있지 않고, 접속할 때 입력합니다.

## 태블릿 번호 규칙
- 산타 굴뚝배달: `번호` (예: 3)
- PELI SLIDE: `S`+번호
- 페리 크리스마스: `T`+번호
- 떨어지는 선물 받기: `C`+번호
- 페리치킨런: `R`+번호

같은 번호는 같은 테이블로 묶여 보입니다.
